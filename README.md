# Aboubacar HEMA, project portfolio

Source of https://abson-dev.github.io, a single-page portfolio of research, data science and AI agent projects.

To add a project, copy one `<article class="card">` block in `index.html`, edit it, and set `data-t` to one or more filters: `food`, `health`, `eo`, `pov`, `ai`, `teach`.
